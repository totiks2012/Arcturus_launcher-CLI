# ОБНОВЛЕНИЕ 15_05_26 -- arcturus_cli-30-adv-menu.sh  -- Arcturus CLI: Release Notes 

Краткий отчет об изменениях и архитектурных решениях при переходе от

итерации 29 к 30. Инструмент окончательно перешел из разряда "скрипта-
помощника" в категорию "центральной нервной системы" рабочего

окружения.

Основные изменения (Changelog)

Модуль Что добавлено / изменено

Иконки

Новое меню поиска SVG/PNG иконок с поддержкой
icons_paths.conf. в котором можно прописать к существующим системным  свои кастомные

Поиск файлов

Внедрен флаг --nth=-1 для fzf в функции
launch_file. -- ищет теперь по имени а не ожидает полный путь

Буфер обмена

Интеграция с wl-copy/xclip для мгновенного
захвата путей.

Инфраструктура

Новая переменная ICONS_CONFIG и расширенные
уведомления.

Почему именно так? (Rationale)

"Инструмент должен быть продолжением руки, а не препятствием
для мысли."



Приоритет имени над путем (--nth=-1): Мозг ищет сущность, а не
координату в файловой системе. Это изменение убирает лишний
визуальный шум при поиске.
Модуль иконок: При администрировании Debian часто требуется
быстрая правка .desktop файлов. Автоматическое копирование пути к
иконке устраняет рутинную работу "найти-выделить-скопировать".
Suckless/KISS: Весь функционал по-прежнему умещается в одном файле
без внешних тяжелых зависимостей, сохраняя Unix-way подход

Находите и запускайте что угодно за секунды! ⚡

## 🌟 Особенности

### 🎯 Умный поиск
- **Мгновенный поиск файлов** по всей системе
- **Интеллектуальный поиск приложений** с автодополнением
- **Fuzzy-поиск** с поддержкой нечеткого ввода
- **Preview файлов** с полной информацией (тип, размер, права доступа)

### 🚀 Производительность  
- **Оптимизированная архитектура** - разделение индексации и UI
- **Использование plocate** - самый быстрый поиск файлов
- **Кэширование приложений** - мгновенная загрузка
- **Фоновая индексация** - не блокирует интерфейс

### 🎮 Удобство использования
- **Управление закрепленными приложениями** с интуитивным интерфейсом
- **Полноценная поисковая система, с удобными самымы востребоваными командами для управления файлами
- **Nord цветовая тема** - легко для глаз
- **Абсурдные уведомления** 😄 - поднимают настроение

### 🔧 Автоматизация
- **Автообновление базы** каждые 30 минут
- **Инкрементальная индексация** - только новые файлы
- **Умный кэш приложений** - обновляется раз в сутки

## 📦 Установка

### Требования

# Установите зависимости одной командой:
sudo apt install fzf plocate libnotify-bin xclip file xdg-utils

Базовая установка
bash

# 1. Клонируйте репозиторий
git clone https://github.com/yourusername/arcturus-launcher.git
cd arcturus-launcher

# 2. Сделайте скрипты исполняемыми
chmod +x arcturus_launcher.sh index_db.sh

# 3. Настройте автоматическую индексацию (ОБЯЗАТЕЛЬНО!)
# Выполните один раз - скрипт всё сделает сам:
./index_db.sh

# 4. Запустите лаунчер
./arcturus_launcher.sh


Что будет настроено:

    ✅ Создание новой базы для поиска файлов почти по всем директориям в системе

    ✅ Обновление каждые 30 минут через cron

    ✅ Фоновая работа без вмешательства пользователя

🎮 Использование
Основное меню
text

Запуск приложения    → Поиск и запуск установленных приложений
Поиск файлов        → Поиск по всей файловой системе  
Положение-Открепить → Управление закрепленными приложениями

Управление закрепленными приложениями

    ⬆ Вверх - переместить приложение выше в списке

    ⬇ Вниз - переместить приложение ниже в списке

    ✕ Открепить - удалить из закрепленных

    ← Назад - вернуться к списку приложений

Действия с файлами

    Запустить (xdg-open) - открыть файл стандартной программой

    Открыть в файловом менеджере - показать в родительской папке

    Копировать полный путь - скопировать абсолютный путь

    Показать информацию - детальная информация о файле

    Редактировать как root - редактирование с правами администратора

Преимущества архитектуры

    ⚡ Мгновенная работа - UI не зависит от индексации

    🔧 Легкая поддержка - компоненты независимы

    🔄 Автоматическое обновление - данные всегда актуальны

    🎯 Надежность - сбои в одном компоненте не влияют на другие

🐛 Устранение неисправностей
Проблемы с индексацией
bash

# Принудительное пересоздание базы
rm file_index.db file_index.db.timestamp
./file_indexer.sh

Проблемы с зависимостями
bash

# Проверка установленных зависимостей
for cmd in fzf plocate notify-send xclip file xdg-open; do
    if command -v $cmd >/dev/null 2>&1; then
        echo "✅ $cmd установлен"
    else
        echo "❌ $cmd отсутствует"
    fi
done
